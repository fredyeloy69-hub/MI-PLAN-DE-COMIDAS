☁️ Sincronizar entre dispositivos (Firebase)

Opcional. Con esto tu plan se sube solo a tu propio Firestore y lo ves igual en el celular y en la PC. Usa el mismo código en todos tus dispositivos.

1) En Firebase Console → tu proyecto → Configuración → “Tus apps” → copia el bloque firebaseConfig y pégalo abajo. 2) En Firestore → Reglas, pega esto y publica: 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /planes/{codigo} {
      allow get, create, update: if true;
      allow list, delete: if false;
    }
  }
}
⚠️ Quien conozca tu código puede leer y cambiar tu plan: usa el código largo que genera el botón y no lo compartas.
